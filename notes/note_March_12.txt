[2 Types parallel system]
- Shared memory: Multiple 'threads' that modify and access 1 memory
- Distributed memory: Multiple 'process' and each of them have their own memory

['Process' components]
- Executable machine lang program (machine instructions)
- Its own memory
- Descriptors of resources allocated to the 'process'
- security info
- state info
- Definitions: 'Process' is an instance of a program that is being executed

[Flynn's Clasification]
-SI: Single instuction
-MI: Multiple instruction
-SD: single data (stream)
-MD: Mutiple data (stream)

- SISD: each core modify their own piece of data (very straight forward)
- SIMD: Same instruction on each core but modify differerent piece of the data - Sync
- MISD: Multiple instruction on each core but modify the same piece of data - Sync
- MIMD: MUltiple instruction on multiple data pieces (quite complex) - Async

[Async paradigm - MIMD]
- Async parallelism
- Each processor is independent
- Operations are no longer in lock-step
	+ Shared data requires synchronized access
	+ We can't ensure data is ready to be accessed by other processor at end of every cycle
- Sychronization mechanism
	+ Mutual exclusion
	+ Shared reading and execlusive update
	+ Caching
	-> Programmer's reponsibility to ensure Synchronization
